# Customer Support Analytics Dashboard

An interactive Power BI dashboard for analyzing customer support performance, customer satisfaction, response time, sentiment, and issue-level trends.

## Overview

This project transforms customer support data into an interactive business intelligence dashboard to identify customer experience patterns and highlight issues that may require operational attention.

The analysis focuses on:

- Customer satisfaction (CSAT)
- Response-time performance
- Customer sentiment
- Support channels
- Issue categories
- Customer volume
- Issue prioritization

## Dashboard

### 1. Executive Overview
Provides a high-level view of customer support performance through key KPIs, customer satisfaction distribution, channel performance, and response-time metrics.

### 2. Customer Experience & Issue Analysis
Examines CSAT, customer volume, sentiment, issue categories, and the relationship between response time and customer satisfaction.

### 3. Issue Prioritization & Action Plan
Uses customer volume and CSAT performance to identify issues that should receive greater attention and supports data-driven prioritization.

## Key Metrics

- Total Customers
- Average CSAT
- Average Response Time
- Customer Satisfaction Rate
- Negative Sentiment
- Customer Volume by Issue Category
